POKESIGNER

Assinador Bitcoin via Bluetooth para placas ESP32 com tela. Firmware 0.6.1.

SIGNER COLOR
Seu navegador não tem suporte a Web Serial. Use o Google Chrome ou o Microsoft Edge no computador (Windows, macOS ou Linux). Celular e Firefox/Safari não funcionam.

▶ 1. GRAVAR FIRMWARE

  1. Ligue a placa no computador pelo cabo USB-C (precisa ser um cabo de dados).
  2. Escolha a sua placa abaixo, clique em Instalar e escolha a porta “USB JTAG/serial debug unit”.
  3. Aceite apagar a memória. A gravação leva cerca de 1 minuto.

Navegador sem Web Serial — use Chrome ou Edge no computador. É preciso abrir esta página por HTTPS ou localhost.

Para atualizar uma placa que já tem o PokeSigner (ou se a gravação não começar): segure o botão BOOT, aperte e solte RESET, solte BOOT e clique em Instalar. Por segurança, o firmware não deixa o computador reiniciar a placa sozinho.

▶ 2. CONFIGURAR SEED

Depois de gravar, clique em Conectar (só aparece a porta da placa). O menu aparece no terminal em até 5 segundos.

desconectado
Atalhos:
Gerar seed (recomendado): as 24 palavras aparecem só na tela da placa, não no computador. Anote em papel e avance com o botão BOOT. Depois confirme aqui as 2 palavras pedidas.
Importar seed: as palavras passam pelo teclado e pela tela deste computador. Só faça isso num computador confiável, de preferência sem internet. A passphrase é digitada com ocultar ligado automaticamente.

▶ 3. PAREAR CELULAR

  1. A tela da placa mostra o fingerprint e o nome PokeSigner-XXXX.
  2. No celular, conecte pela PokeWallet (ou pelo app do sistema). A placa mostra um código de 6 dígitos: digite no celular.
  3. Para assinar: revise as páginas na tela com BOOT (ou pelo celular). Na última aparece um código de 6 dígitos: digite no celular ou segure BOOT 2 s para aprovar. Toque rápido rejeita.
  4. Se a imagem da placa ficar de cabeça para baixo ou espelhada, use o atalho girar tela até ficar certa.

Este instalador roda inteiro no seu navegador. Nenhum dado digitado é enviado para a internet; a única coisa baixada é a biblioteca de gravação (esp-web-tools).
